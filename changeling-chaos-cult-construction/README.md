# Строительство культов Перевёртыша в поселениях Хаоса

Хайчай в Равнинах Сэнь использует тип алтаря Хаоса, а Вэй-Цзинь и Красная крепость — тип тёмной крепости. В версии игры 9.0.5 ни одна из 16 цепочек культов Перевёртыша не включена в разрешения этих типов. У других особых поселений, например фабрик Гномов Хаоса, эти разрешения есть. Существующие постройки видны в слотах, а меню нового строительства остаётся пустым.

Пакет добавляет 32 разрешения в `settlement_type_to_building_chains_junctions_tables`. Они распространяются на алтари Хаоса и тёмные крепости, включая поселения, которые сохранили тип после смены владельца. Цены, требования, действующие постройки и очереди определяет игра.

Сборка из корня репозитория выполняется командой `node changeling-chaos-cult-construction/build.mjs [папка_data]` на Node.js 24+. Сборщик читает `db.pack` установленной игры, берёт набор цепочек из штатных разрешений фабрик и проверяет таблицу в собранном пакете. Если игра уже содержит разрешение для цепочки, повторная строка не добавляется.

`changeling_chaos_cult_construction.pack` загружается из `data` при запуске игры как пакет Movie. Подходит для существующего сейва. Сборка и записи таблицы проверены. Отображение меню в игре ещё предстоит проверить.
