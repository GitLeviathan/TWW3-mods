# 3D-просмотр выбранной формы Перевёртыша

**Тестовая версия с подтверждённым дефектом: модель в игре остаётся невидимой.** Подпись и переключение режимов работают. Журнал подтверждает определение выделенной формы и создание её UI-компонента (`MASK_PREVIEW|loaded`), но это не подтверждает успешный рендер. Пользователь проверил пустой просмотр Дуртху; состояние не считается исправленным.

Кнопка справа в «Бесформенном ужасе» переключает характеристики и просмотр. Загрузка использует файл боевой формы напрямую, без наличия её владельца на карте: `main_units → unit_variants → variants`. Манифест текущей установки содержит 1432 записи, включая варианты, и список неразрешённых записей. При смене формы предыдущий компонент удаляется. `ComponentModelController` предусмотрен для вращения и масштаба; работа рендера и управления пока не подтверждена.

Сборка текущего манифеста из корня репозитория: `node changeling-form-preview/build.mjs`. Нужны Node.js 24+ и установленная игра: сборщик читает штатный UI из `ui3.pack`. Путь к `ui3.pack` можно передать первым аргументом. Результат — `00_changeling_formless_model_preview.pack`; заменять его в `data` только при закрытой игре.

Для обновления манифеста под установленную игру и активные моды:

```text
node changeling-form-preview/prepare.mjs
node changeling-form-preview/index-animations.mjs
node changeling-form-preview/build-assets.mjs
node changeling-form-preview/build.mjs
```

Подготовка получает схемы из [rpfm-schemas](https://github.com/Frodo45127/rpfm-schemas); индексатор читает локальные архивы анимаций. Извлечённые игровые XML, схема и кеш индексов в Git не включаются. Обновление манифеста использует пути D: из скриптов и последний `modified.log`; для другой установки их нужно настроить.

Проверки: `python changeling-form-preview/verify.py` и `python changeling-form-preview/test-preview.py`. Второй тест требует Lupa; дополнительный путь задаётся `TWW3_LUPA_PATH`. Они проверяют структуру пакета и исполнение Lua с тестовым UI, а не графический движок.
