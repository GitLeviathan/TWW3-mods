# Посох Трикстера

Срок восстановления девяти Великих перемен — один ход за счёт эффектов экипированного посоха. «Открыть завесу» полностью исключена: её собственный и целевой сроки остаются штатными. Описание предмета сохранено без изменения; `staff-description.loc` является исходным ресурсом локализации.

Сборка из корня репозитория: `node tricksters-staff/build.mjs` (Node.js 24+, установленная игра по стандартному для проекта пути на D:). Сборщик читает реальные базовые сроки из `db.pack`, проверяет исключение «Открыть завесу» и повторное чтение записанных таблиц.

Результат `tricksters_staff_transfer_settlement.pack` заменяет одноимённый пакет в `data` при закрытой игре. Другие эффекты могут дополнительно менять итоговый срок. Уже запущенные таймеры сохранения не редактируются.
