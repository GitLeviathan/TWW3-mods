# Моды для Перевёртыша в Total War: WARHAMMER III

- [Дальний прыжок](changeling-teleport/README.md) добавляет армиям Обманщиков прыжок к выбранному поселению на карте кампании.
- [TalkHammer: True Changeling Roleplay](changeling-diplomacy/README.md) позволяет Перевёртышу вести переговоры от лица фракции выбранного облика.
- [Распространение культов Перевёртыша](changeling-cult-tracker/README.md) показывает, куда может расшириться каждый культ Обманщиков.
- [Стадии порчи Slaanesh Expanded в TalkHammer](talkhammer-slaanesh/README.md): бонус отношения и условия согласия вассала.
- [Посох Трикстера](tricksters-staff/README.md): восстановление девяти Великих перемен за один ход, без изменения «Открыть завесу» и описания предмета.
- [3D-просмотр форм](changeling-form-preview/README.md): экспериментальная версия; модель сейчас остаётся невидимой в игре.

Каждый текущий мод находится в отдельной папке. Исходники, тесты и сборщики версионируются; собранные `.pack` и извлечённые игровые ресурсы остаются локальными согласно `AGENTS.md`. Папка `disguise` сохраняет только материалы прежней версии; действующая дипломатия — в `changeling-diplomacy`.
