# Дальний прыжок

Мод для кампании Перевёртыша в Total War: WARHAMMER III.

1. Из корня репозитория выполни `node ./changeling-teleport/build.mjs`.
2. Скопируй собранный `changeling_teleport_range.pack` в папку `data` игры и включи его в менеджере модов.
3. Выбери армию Обманщиков в режиме «Телепортация», нажми маленький значок рядом с кнопкой режима передвижения, выбери поселение на карте и подтверди прыжок.

Прыжок переносит армию к поселению и тратит оставшиеся очки хода. После исследования технологии «Телепортация» Ветра Магии за дальний прыжок не расходуются, и предупреждение об их расходе исчезает.
