# Распространение культов Перевёртыша

Цифра у значка культа Обманщиков показывает, сколько соседних поселений подходят для распространения. Наведи на цифру, чтобы увидеть названия этих поселений и текущий шанс распространения в начале хода. Если подходящих соседей нет, цифра скрыта.

В списке «Провинции» цифра у значка культа показывает общее число доступных целей для культов этой провинции. Общая для нескольких культов цель учитывается один раз. В подсказке перечислены цели и шансы распространения по культам.

1. Установи Node.js 22.15 или новее и выполни из корня репозитория `node ./changeling-cult-tracker/build.mjs`. Если игра установлена в другой папке, передай путь к её папке `data` первым аргументом.
2. Скопируй `changeling_cult_tracker.pack` из папки мода в `data` игры и включи его в менеджере модов.
3. Загрузи кампанию Перевёртыша. Мод отображает данные текущей кампании, поэтому подходит для уже начатой игры.

Разметка значков встраивается в штатную панель поселения `city_info_bar.twui.xml` и список провинций `dropdown_regions.twui.xml`. После обновления игры пересобери пакет. Если другой мод заменяет ту же панель, в игре будет действовать разметка пакета с более высоким приоритетом.

Тест подсчёта запускается командой `lua tracker.test.lua` из папки мода.
