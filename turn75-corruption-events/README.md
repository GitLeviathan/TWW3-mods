# Однократные события порчи на следующем ходу

Временный инструмент для явно помеченной кампании Обманщиков, сохранённой на 75-м ходу. На начале собственного хода 76 ставит два локальных флага поражения внутри штатного обработчика Slaanesh Victories. Его обычный цикл повышает счётчики Репанс и Мяо Ин с 2 до 3 и вызывает `rep_defeat_3` / `miao_defeat_3`.

Перед событием черты и счётчики должны оставаться на 2: стадия 3 применяется родным эффектом дилеммы. По реальным DB-строкам обе опции дают `n_rep_defeat_lvl3` / `n_miao_defeat_lvl3`; идентификаторы целей совпадают с персонажами в ремонтируемом сейве. Это не имитация уведомления и не повторная прибавка очков.

Защита: токен в `codex_turn75_rep_miao_pending`, фракция и локальный игрок Обманщики, ход строго 76, оба счётчика строго 2, отсутствие `codex_turn75_rep_miao_done`. После запуска маркер потребляется и сохраняется done. Непомеченные кампании не затрагиваются. Если условия изменились, операция пропускается без отката счётчиков.

```text
node turn75-corruption-events/build.mjs <64-символьный-токен> [путь_к_@n_SlaaneshVictories.pack]
python turn75-corruption-events/test_events.py
```

Нужны Node.js 24+, оригинальный мод Slaanesh Victories, для тестов — Lupa Lua 5.1. `TWW3_LUPA_PATH` задаёт путь к локальной Lupa. Тестовый стенд ориентирован на токен подготовленного сейва; сам сейв и оригинальный мод в Git не входят.

`turn75_corruption_events.pack` имеет тип Movie и автоматически загружается из `data` после полного перезапуска. Он переопределяет один скрипт исходного мода с небольшим добавлением; остальные исходные байты сохранены. После двух событий и нового сохранения этот временный файл следует убрать из `data`, чтобы он не перекрывал будущие обновления Slaanesh Victories. Другие моды, заменяющие тот же скрипт, требуют согласования.

Проверен полный штатный Lua-цикл: отсутствие события при загрузке/неправильном ходе/чужой фракции, правильные две дилеммы, счётчики 2→3, отсутствие повторов и повторного запуска после загрузки. Наступление хода 76 в самой игре ещё не проверено. SHA-256 подготовленного пакета: `c2a277cc80ddc37449f3b26ce22d243212d991a59dc5940e5d1620f5218e7672`.
